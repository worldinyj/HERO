# S03 검토 결과 작성·전달 — 2026-10-12

관리자 시나리오 화면에서 검토 대상 일치를 확인한 뒤 영역별 실제 사람 판정과 근거를 작성해 JSON으로 다운로드한다. 담당자는 같은 현재 파일 SHA에 대한 결과인지 사전검사한 뒤 기존 검토 기록에 반영한다.

## 화면 흐름

1. 저장된 S03 버전 또는 입력 JSON의 검토 대상 일치를 확인한다.
2. 직접 검토한 영역과 통과/보완 필요 판정을 선택한다. 판정은 기본 선택하지 않는다.
3. 검토자 성명 또는 공식 역할, 한국 날짜 기준 검토일, 추적 가능한 근거 참조를 입력한다. 보완 필요에는 보완 내용을 필수로 입력한다.
4. 직접 검토 및 판정·근거 확인을 체크한 뒤 결과 파일을 다운로드한다.
5. 담당자에게 파일과 근거를 전달하여 검토 기록 반영을 진행한다.

내용 변경·목록 갱신·검토 대상 변경으로 일치 확인이 해제되면 다운로드가 잠기고 직접 검토 확인은 해제된다. 작성 내용은 같은 화면의 메모리에 유지되어 재확인 후 이어 쓸 수 있다. 입력 내용을 바꾸면 직접 검토 확인을 다시 해야 한다.

입력은 localStorage·IndexedDB·서버에 자동 저장하거나 전달하지 않는다. 파일에 시나리오 원문은 포함하지 않으며 시나리오 ID·버전·원본 파일 SHA와 해당 영역의 검토 결과만 넣는다. 다운로드만으로 공개 진행 상태나 최종 승인 상태는 변경되지 않는다. 화면 이탈/새로고침 후 작성 내용은 복원하지 않는다.

## 담당자의 파일 가져오기

```bash
# 사전검사: 어떤 파일도 바꾸지 않는다.
pnpm import:scenario-review -- --file=./review-result.json

# 실제 사람 검토 및 근거를 확인한 담당자가 기록을 적용한다.
pnpm import:scenario-review -- --file=./review-result.json --apply --confirm-human-review

# 검토 기록 검증·배포 요약 갱신
pnpm check:human-review-evidence
pnpm build:scenario-review-status
pnpm check:scenario-review-status
```

가져오기 도구는 현재 시나리오 ID·버전·파일 SHA, 영역별 SHA, 영역 중복, 실제 달력 날짜와 미래 날짜, 검토자·근거·판정·HOLD 사유를 검사한다. 1~5개 영역을 받아 서로 다른 전문가의 부분 검토도 지원한다. 최종 승격은 기존 5개 영역의 동일-SHA PASS와 출처·권리 게이트를 유지한다.

- 같은 결과 파일을 다시 적용하면 이미 기록된 동일 결과는 추가하지 않는다. 이전 PASS 파일을 반복 적용해 후속 HOLD를 되살리지 않는다.
- 같은 SHA·영역에 더 최근 날짜의 기록이 있으면 과거 판정의 추가를 거부한다.
- 새 기록을 넣기 전에 파일 전체를 검증한다. 뒤의 행이 실패해도 앞의 행만 부분 적용하지 않는다.
- 동시에 실행되는 가져오기는 전용 lock으로 거부하고, 적용 파일은 임시 파일 작성 후 rename한다. 다른 편집 도구/기존 CLI가 같은 lock을 공유하는 것은 아니므로 담당자는 해당 파일의 다른 편집과 가져오기를 동시에 실행하지 않는다.
- 이미 공식 승인된 콘텐츠에는 새 기록을 추가하지 않는다. 검토 상태로 돌아가는 기존 절차를 먼저 수행한다. 가져오기는 승인·게시·시즌 상태를 자동 변경하지 않는다.
- `--root`는 격리된 복제본/테스트 작업용이며, 다운로드 파일은 기록 대상 경로를 지정할 수 없다.

## 검증

단위 테스트 390개(엔진 19·웹 371) 통과. 새 validation과 격리된 임시 저장소 CLI 시험은 해시/버전 오류, 실제·미래 날짜, 부분 HOLD, 중복 영역, 누락된 근거, preflight 무변경, 명시적 적용 확인, 중복 재적용, 과거 기록 거부, 전체 검증 후 적용, 동시 가져오기 lock과 승인 대상 차단을 확인했다. 실제 저장소의 사람 검토 기록은 변경하지 않았다.

두 모바일 크기의 검토 패널 회귀 14개에서 다운로드 JSON의 필드·HOLD 유지·자동 승인 없음·입력 변경 잠금·작성 내용 유지·접근성과 가로 넘침을 확인했다. 최종 전체 CI 및 운영 배포 기록은 PR에 남긴다.
