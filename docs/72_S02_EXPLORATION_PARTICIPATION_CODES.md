# S02 탐색형 체험 참여코드와 진행 기록

확인일: 2026-10-15 · 사용자 확인에 근거한 첫 파일럿 운영 기록.

## 참여코드

| 사업소 | 참여코드 | 참여 인원 | 체험 상태 | 의견 상태 | 현재 보고된 문제 |
|---|---|---:|---|---|---|
| 중앙연구원 | `CRI02` | 1명 | 완료 · 사용자 확인 | 제출 대기 | 없음 · 사용자 확인 |
| 한울3발 | `HANUL02` | 1명 | 완료 · 사용자 확인 | 제출 대기 | 없음 · 사용자 확인 |

이 코드는 의견을 첫 파일럿과 연결하기 위한 선택 입력값이다. 로그인 암호·초대 토큰·접근 권한이 아니며 체험 완료를 자동 인증하지 않는다. 개인 이름과 코드의 연결은 담당자가 별도로 관리한다. 초대 수락 과정, 로그인 과정, 개별 행동 기록과 소요 시간은 직접 확인하지 않았다.

‘문제 없음’은 현재 사용자에게 보고된 진행 문제가 없다는 뜻이다. 상세 사용성 의견 수집 완료, 모든 기기 검증, 학습 효과 입증 또는 최종 제품 승인을 의미하지 않는다. 실제 의견을 받은 뒤 상태와 개선 필요 사항을 갱신한다.

## 접속과 의견 전달

- [S02 탐색형 체험](https://hero-dnr.pages.dev/experience/s02-exploration)
- [익명 의견 접수 폼](https://secondlifelol.notion.site/147e51907ccf4bbb9060816817335bb3?pvs=105)
- [담당자용 비공개 Notion 관리 페이지](https://app.notion.com/p/3fa7d85ba9e481219849f87d39a581d0)
- [파일럿 진행 안내](71_S02_EXPLORATION_PILOT.md)

참여자는 폼에서 화면을 ‘탐색형 체험’으로 선택하고 참여코드를 선택적으로 입력한다. 이름·이메일 입력은 요구하지 않는다. 폼 응답은 Notion 관리 목록에 저장된다. 앱 입력과 판단 기록은 자동으로 옮겨지지 않으며, 행동 순서를 함께 검토하려면 JSON 파일을 내려받아 담당자에게 별도로 전달한다.

체험은 승인된 S02 v4의 식별·확인 두 판단을 발췌한 별도 체험이다. 경쟁 순위·HP·학습기록에 반영하지 않는다. 이후 참여자 수가 늘면 동일 코드로 개인을 구별할 수 없으므로 이 표를 수정하고 별도 코드를 부여한다.

## 다음 처리

1. 상세 의견이 도착하면 원문을 보존하고 발생 화면·기기·재현 여부를 확인한다.
2. 진행 장애, 판단 혼동, 이용 편의 순으로 검토한다.
3. 사람·기술·조직 조건의 연결을 살피고 개선 작업 및 운영 확인 근거를 연결한다.

이번 확인은 앞으로 의견 수집과 독립적으로 진행할 수 있는 성능·접근성·코드 품질 점검을 계속하는 근거로 사용한다.
