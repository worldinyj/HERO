## 승인 대상

- 「1장 · 오늘 오전까지 끝내야 합니다」, `s01_time_pressure` v5.
- 파일: `scenarios/data/S01_time_pressure_v1.json`.
- 승인 원문 SHA-256: `0b3558cf7eb9961d932ae2d7eb229e873685c2436f4959eee2082af45443a525`.
- 미리보기 정규화 SHA-256: `197ff9b563488676167898a1c6fe3f7eb19608383f413c58f97aedcaeb591282`.
- 근거: `scenarios/research/approvals/S01_V5_USER_APPROVAL_20261015.json`.
- 전체 콘텐츠 검토본을 제공한 뒤 받은 한 사용자의 직접 승인이다. 안내된 다섯 관점을 같은 해시에 기록했으며 별도 전문가 5명이나 실제 열람 행동을 확인했다는 의미가 아니다.
- 콘텐츠 변경 없이 초안에서 공개용 경로로 이동했다. 향후 내용 변경은 새 버전과 재검토를 거친다.

## 검증

출처·권리·원인 추적성·콘텐츠 승격·사람 검토·승인 해시 검사와 전체 공개 JSON 4개 스키마 검증을 통과했다. S01 전 경로 시뮬레이션은 승인 전 v5 측정 결과와 전체가 동일하다. 관리자 검토 관련 기존 단위 테스트 11개와 TypeScript·프로덕션 빌드도 통과했다.

마지막 초안이 공개되어 `scenarios/drafts`가 비게 되므로 CI와 로컬 심화 QA는 초안이 있을 때만 초안 검증을 실행하고, CI의 초안 시뮬레이션도 빈 폴더를 건너뛰도록 보완했다. 공개 콘텐츠 검증은 계속 필수다. 빈 폴더는 `.gitkeep`으로 유지한다.
