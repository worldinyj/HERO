# 시나리오 상태 변경 확인

관리자 시나리오 버전의 상태 버튼을 누르면 시나리오명·slug·버전·현재 상태·목표 상태·변경 영향을 확인하는 모달이 열린다. 확인하기 전과 취소할 때에는 상태 변경 API를 호출하지 않는다. 배포는 같은 시나리오의 기존 published 버전을 보관한다는 점과 활성 시즌 버전 연결이 별도로 필요하다는 점을 안내한다. 승인/배포 상태 변경은 출처·권리·HF·익명화 검토와 공식 출시 승인 증거를 대신하지 않는다.

네이티브 dialog로 배경 접근을 막고 취소 버튼에 초기 포커스를 둔다. Tab은 창 안에서 순환하고 Escape 또는 취소로 닫으면 원래 버튼으로 돌아간다. 변경 결과로 버튼이 사라졌다면 시나리오 관리 제목으로 포커스를 돌린다. 처리 중 확인/취소를 비활성화하고 Escape를 막으며, ref 잠금으로 중복 요청을 차단한다.

서버의 updated 표시와 응답의 ID·버전·목표 상태가 모두 일치해야 성공으로 처리한다. HTTP 오류 응답을 복제해 기존 본문을 소비하지 않고 알려진 코드만 한국어로 안내한다. 임의 서버 메시지나 DB 오류를 화면에 노출하지 않는다. 결과를 확인하지 못하면 취소 후 새로 추가한 목록 새로고침으로 반영 여부를 확인한다. 자동 재시도는 하지 않는다.

## 검증

- 타입 검사, ESLint, 단위 테스트 335개(engine 19/web 316), 웹 빌드, 초기 JS 크기와 소셜 메타데이터 게이트 통과.
- 모바일 390×844 / 360×800: 기존 미리보기 10개 + 상태 변경 8개 총 18개 통과.
- 취소/Escape 무요청, 포커스 복귀와 순환, 처리 중 닫기 방지·요청 1회, HTTP 409 오류 안내 후 명시적 재시도, 다른 ID의 성공 응답 거절 후 목록 재조회 검증.
- 상태 확인 모달의 WCAG 2.2 AA 관련 axe 자동 검사 포함. 실제 기기·보조기기 검증을 대신하지 않는다.

테스트는 루프백 Supabase API 응답을 fixture로 가로챈다. 운영 DB의 시나리오를 생성하거나 승인·배포·보관 상태로 바꾸지 않는다. 이번 변경은 웹에만 해당하며 Edge Function/DB 마이그레이션은 없다. 기존 상태 변경 API의 권한·전이·게시 처리는 그대로 사용한다. DB 트랜잭션 원자성이나 다중 관리자 동시 변경 제어를 추가한 작업은 아니다.
