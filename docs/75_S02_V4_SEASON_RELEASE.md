## 후속 확인

### 참여자가 확인하는 순서

1. 인터넷이 연결된 상태에서 [HERO 캠페인](https://hero-dnr.pages.dev/)에 본인의 참여자 계정으로 로그인한다. 교육담당자·관리자 계정은 경쟁 플레이 대상이 아니다.
2. 2026년 10월 시즌에 「2장 · 아마 이 설비가 맞을 겁니다」가 나타나는지 확인하고 전체 경쟁판으로 진입한다. 별도의 ‘탐색형 체험’ 입구와 구분한다.
3. 브리핑에서 시작해 정보를 확인하고 방벽·판단을 선택하며 결말까지 진행한다. 특정 결말이나 높은 점수를 맞출 필요는 없다.
4. 결말의 ‘결과 돌아보기’를 누르고, 방벽 약화 시점을 선택해 ‘내 생각 확인’을 누른다. 다음 방벽 타임라인에서 ‘HP 리뷰 보기’까지 진행한다. 결말 화면 도착만으로 서버 제출이 끝나는 것은 아니다.
5. **‘서버 검증 완료 · 시즌 기록에 반영되었습니다.’** 문구를 확인한다. 오프라인 보관·제출 대기·검증 실패는 완료 확인과 구분한다.
6. [내 기록](https://hero-dnr.pages.dev/me)에서 S02가 ‘장별 최고 기록’에 나타나는지, 완료 횟수·최근 완료 시각과 HP가 반영되는지 확인한다. 새로고침 후에도 유지되는지 확인한다. 장별 최고 기록과 현재 플레이의 HP는 반복 플레이 시 다를 수 있다.

참여자는 ‘S02 완료 / 서버 검증 완료 문구 확인 / 내 기록 S02 확인’ 정도를 알려주면 된다. 문제가 있으면 화면 이름·오류 문구·기기/브라우저를 남긴다. 비밀번호·인증번호를 전달할 필요는 없다.

### 운영자가 확인하는 범위

관리자는 감사 이력의 학습 세션 완료 이벤트를 확인하고 담당자는 허용된 사업소 학습 현황과 대조한다. 이 배포 확인 당시 서버 제출은 회고 응답 여부와 타임라인 열람 여부를평가에 사용했고, 사용자가 선택한 ‘방벽 약화 시점’ 자체는 별도 회고 응답으로 저장하지 않았다. 개인 기록 화면에는 요약과 장별 최고 기록이 표시된다. 당시 ‘회고 저장 확인’이라는 표현은 회고 단계 이후 결과 제출을 뜻했다. 후속 개선은 [경쟁 플레이 회고 선택 보존](76_COMPETITIVE_REFLECTION_SELECTION.md)에 기록한다. 자동화 테스트는 저장 계약을 점검할 수 있지만 실제 참여자의 로그인·기기·연결 상태를 통과한 이용 확인을 대체하지 않는다.

참여자 계정의 실제 S02 전체 경쟁판 완료·HP·회고 저장은 이번 관리자 점검으로 검증하지 않았다. 운영 계정의 경쟁 플레이 권한을 바꾸거나 실제 참여자 명의의 테스트 기록을 만들지 않았다. 다음 확인은 참여자 캠페인에서 S02 진입과 완료 후 기록을 실제 이용 결과로 확인하는 것이다.

[탐색형 체험 참여코드와 진행 기록](72_S02_EXPLORATION_PARTICIPATION_CODES.md)은 별도다. 탐색형 체험에는 경쟁 HP·순위가 없고 상세 의견은 제출 대기다. S01은 이번 배포 대상에 포함하지 않았다. 이후 본문 수정은 새 버전으로 변경 내용 검토·승인 후 배포한다.
