# 공개 시나리오 회고의 읽기·탐색 품질 개선

2026-10-15.

## 문제와 변경

S01 v5의 관련 대책에는 공식 조치·2012년 당시 향후 계획·HERO 학습 제안이 명시적으로 구분되어 있다. 그런데 공통 회고 화면은 모든 항목을 공식 조사자료의 조치 요약이라고 설명했다. 공통 안내를 각 항목에 표시된 출처 경계에 따라 읽도록 수정하고, 당시 계획을 현재의 완료 사실로 보지 않도록 명확히 했다.

긴 실사건 회고 위에 ‘사건과 원인’, ‘인과사슬’, ‘방벽과 대책’, ‘핵심 교훈’ 바로가기를 추가했다. 존재하는 절에만 연결하며, 방벽이 없고 대책만 있는 경우 대책으로 연결한다. 일반 링크와 제목 초점을 사용해 키보드와 보조기술에서도 이동할 수 있다. 새 스타일·라이브러리·요청은 추가하지 않았다.

## 콘텐츠·HTO 경계

S01 v5, S02 v4, S03 v7 JSON·버전·승인 해시·점수·플레이·시즌 연결은 변경하지 않는다. 개선은 같은 회고를 사용하는 경쟁 플레이와 관리자 미리보기에 적용된다. S02 HTO 시안은 별도 관리자 검토용이며 이번 작업으로 참여자 화면에 공개하거나 콘텐츠 승인을 부여하지 않는다.

## 검증

- 기존 회고 렌더 테스트 2개 통과.
- 360px·390px에서 공개 S01 전체 내용을 관리자 미리보기로 완료한 뒤 바로가기 4개를 키보드로 실행: 해당 제목 초점 이동 확인.
- 같은 모바일 검증에서 가로 넘침 없음, 회고 영역 axe 접근성 위반 없음, 실제 학습 세션·제출 요청 및 IndexedDB 기록 생성 없음 확인. 모든 API는 loopback mock으로 처리한다.
- lint, TypeScript·프로덕션 빌드, 경로 분리·클라이언트 비밀정보 검사 통과.
- 세 공개 콘텐츠의 승인 해시 검사 통과.

자동 검증은 실제 참여자의 완료·학습 효과·의견 수집을 대체하지 않는다.
