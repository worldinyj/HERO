# 관리자 시나리오 버전 비교

관리자 시나리오 관리에서 변경 전 기준 버전을 선택하고, 같은 시나리오의 다른 저장 버전 또는 입력 중인 JSON을 변경 후 대상으로 비교한다. 서로 다른 시나리오 또는 동일한 저장 버전을 비교 대상으로 선택하지 못한다. 동일 slug의 유효한 schema/graph 검증을 통과한 JSON만 편집기 비교에 사용할 수 있다.

읽기 전용 admin-scenario preview action을 재사용한다. 응답의 버전 UUID·내용의 버전 번호·시나리오 slug를 모두 확인한다. 조회가 실패하거나 응답이 일치하지 않으면 결과를 보여주지 않는다. 편집기 JSON은 실행 버튼을 누른 순간 복제하므로 이후 편집을 진행해도 실행 중인 비교의 대상이 바뀌지 않는다. 취소·선택 변경·목록 갱신·컴포넌트 해제 후 도착한 이전 응답은 폐기한다.

조회한 버전의 실제 제목을 전후 안내에 사용한다. 목록의 시나리오 제목은 새 버전 업로드로 바뀔 수 있으므로 과거 버전의 제목으로 간주하지 않는다. schema 검증에서 기본값을 채운 내용끼리 비교하므로 기본값 생략과 명시는 동등하게 취급한다.

## 비교 규칙과 화면

- 기본 설정, 초기 상태, 장면·선택지, 실사건 회고로 분류하고 추가/삭제/변경을 표시한다.
- 선택지와 정보 행동은 actionId로 정렬 대응한다. 재배열은 별도의 작성 순서 변경으로 표시하며 실제 플레이 셔플과 구분한다.
- 객체의 키 삽입 순서는 내용 변경으로 취급하지 않는다. 버전 번호는 전후 버전 안내에서 보여주고 내용 변경 개수에서는 제외한다.
- 다른 배열은 인덱스별로 비교한다. 출처/교훈 목록의 순서 변경은 변경 사항에 포함된다.
- 0, false, 빈 배열과 항목 부재를 구분한다. 원본을 수정하지 않는다.
- 20개씩 더 펼칠 수 있으며 전체 변경 개수와 현재 표시 개수를 명시한다. 각 변경을 열면 한국어 항목명과 정확한 JSON Pointer 경로 및 전후 값을 확인한다. 경로의 `/`와 `~`는 이스케이프해 고유 장면 ID와 구분한다.
- 결과 제목으로 포커스를 옮기고 닫기/취소 후 실행 버튼으로 돌아간다. 편집으로 버튼이 비활성화된 경우 비교 제목으로 돌아간다.

시나리오/승인 상태/학습기록·HP·순위는 변경하지 않는다. 기존 API rate-limit 카운터는 사용한다. DB 마이그레이션과 Edge Function 변경은 없고 웹만 배포한다. 비교 결과는 출처·권리·인적요인·익명화 검토나 공식 출시 승인을 대신하지 않는다.

## 검증 (2026-10-11 KST)

타입 검사·ESLint·단위 테스트 342개(engine 19/web 323)·웹 빌드·초기 JS 크기/소셜 메타데이터 게이트 통과. diff 단위 테스트는 행동 ID 대응, 순서 변경, 추가/삭제, 초기 조건·노드 유형·회고, 객체 키 순서, 값 부재, 경로 특수문자와 prototype 이름 처리 및 다른 시나리오 거절을 확인한다.

모바일 390×844 / 360×800에서 비교 22개, 기존 미리보기·상태 변경 18개(총 40개) 확인. 저장 버전 비교, 편집 사본 고정, 다른 시나리오/유효하지 않은 JSON 차단, ID·버전·slug 불일치, 취소 후 늦은 응답, 선택 변경, 비활성 실행 버튼의 포커스 복구, 페이지 이후 전체 변경 열람, 빈 목록 및 버전 번호만 변경된 동일 내용 안내 포함. 비교 결과 axe WCAG 2.2 AA 관련 자동 검사 통과.

모바일 검사는 루프백 API fixture이며 실제 운영 저장 버전 조회/비교 검증을 대신하지 않는다. 운영 DB에 테스트 시나리오를 생성하거나 상태를 바꾸지 않는다.

## 운영 반영 (2026-10-11 KST)

PR #93의 최종 커밋에서 quality·pgTAP·mobile-flow·Cloudflare Preview 검사가 통과한 뒤 병합 커밋 `a820b668883625fc3ba8b73345922e1cab979c1b`를 배포했다. Cloudflare production 배포 `5ae289a6-c58c-4502-aaf6-86d16663c05f`가 success이며 운영 자동 배포는 비활성 상태다. 운영 HTTP 34개 검사와 HTML·초기 JS·CSS·관리자 시나리오 JS의 로컬 빌드 바이트 일치를 확인했다.

로그인된 실제 관리자 화면에서 버전 비교 영역과 빈 목록 안내를 확인했다. 운영 저장 버전이 0개여서 실제 저장 버전 비교는 수행하지 않았다. 비교/취소/응답 계약은 루프백 fixture 검사 결과로 구분하며 운영 DB 데이터 또는 승인/게시 상태는 바꾸지 않았다. 증빙: `ops/scenario-version-comparison-deployment-20261011.json`.
