# 관리자 S03 검토 진행 화면 — 2026-10-12

`/admin/scenarios`에 S03 v4의 출처·권리, 필수 사람 검토 5개 영역, 최종 콘텐츠 승인 상태와 검토 대상 내용 확인을 추가했다.

## 기록 기준

- `promotion-status.json` 및 `human-review-evidence.json`에서 현재 S03 파일 SHA에 대한 최신 영역별 결과만 요약한다. 이전 내용의 PASS는 승계하지 않으며 같은 영역의 후속 HOLD가 PASS를 대체한다.
- 현재 S03은 출처·권리 확인 완료, 필수 검토 **0/5**, 최종 콘텐츠 승인 대기다. DB 버전의 approved/published 상태만으로 사람 검토를 통과 표시하지 않는다.
- 생성 요약은 시나리오 ID·제목·버전·해시·영역별 상태·승인 여부만 포함한다. 원본 시나리오, 내부 출처 링크, 검토자 이름, 근거 참조, 메모는 웹 번들에 넣지 않는다. 관리 화면은 기존 관리자 라우트 권한을 유지한다. 정적 웹 번들에는 개인·내부 정보를 포함하지 않는 요약만 들어간다.
- 현재 배포본 기준의 기록이므로 저장소에 검토 결과가 추가되면 요약 재생성·다음 배포 후 화면에 반영된다. 실시간 DB 검토 기록 또는 화면에서 기록 저장하는 기능은 아니다.

## 검토 대상 확인

저장된 S03 버전 또는 편집기의 S03 JSON을 선택해 기존 읽기 전용 preview API로 확인한다. 저장 응답의 version ID·버전·시나리오 ID를 검사하고, 스키마 검증 후 정규화한 내용의 SHA-256을 배포 검토 대상과 비교한다. JSON 공백·객체 키 순서 차이는 무시하지만 배열 순서와 내용 변경은 일치로 인정하지 않는다.

일치하면 기존 검토용 미리보기를 열 수 있다. 다른 버전·내용 변경·조회 오류는 확인을 차단한다. 선택·목록·입력 JSON 변경과 화면 이탈은 진행 중 조회를 무효화하여 늦은 응답이 확인 상태를 되살리지 못한다. 닫기 후 원래 버튼으로 포커스를 돌려준다.

화면의 파일 SHA는 실제 승인 기록에 사용하는 원본 파일 바이트의 해시다. 브라우저 내용 대조 해시는 별도 정규화 해시이며 파일 승인 해시를 대체하지 않는다.

## 담당자의 승인 기록 절차

실제 검토자가 HF 정확성, 운전·정비 맥락, 익명화·정보 노출, Just Culture, 실사건 회고별 판정·검토자·날짜·근거를 확정한다. 기록은 기존 [HUMAN_REVIEW_EVIDENCE_GUIDE.md](../scenarios/research/HUMAN_REVIEW_EVIDENCE_GUIDE.md)의 `record:scenario-review` 절차로 등록한다. 이번 변경에서 검토 결과를 임의 생성하거나 시나리오를 승인·게시·시즌 배정하지 않았다. 운영 DB·Edge·콘텐츠 변경도 없다.

요약 갱신 및 검사:

```bash
pnpm build:scenario-review-status
pnpm check:scenario-review-status
pnpm build
```

루트 build와 CI가 요약의 최신성을 검사한다. 실제 사람 검토·출처 gate는 기존 `check:human-review-evidence`, `check:scenario-promotion`, `promote:scenario` 정책을 유지한다.
