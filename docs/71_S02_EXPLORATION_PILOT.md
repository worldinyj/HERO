# S02 탐색형 체험 첫 파일럿 진행

중앙연구원과 한울3발의 작업자 각 1명이 S02 탐색형 체험을 이용하고, 조사 공간의 조작과 판단에 도움이 된 점을 확인한다. 이 2명 점검은 사용성 개선에 활용한다. 전체 S02 경쟁 플레이나 S03 학습 평가와는 별도다.

체험은 승인된 S02 v4의 식별·확인 두 판단을 사용한다. HP·순위·학습기록에 반영하지 않으며 진행과 의견을 자동 저장하지 않는다. 실제 작업 결과를 판정하지 않고 확인 단서·방벽·판단 순서를 회고한다.

## 담당자 준비

- 사업소 교육담당자는 참여자가 본인 계정으로 로그인할 수 있는지 확인한다. 기존 초대가 있으면 먼저 수락 여부를 확인하고 중복 발급하지 않는다.
- 참여코드는 중앙연구원 `CRI02`, 한울3발 `HANUL02`를 사용한다. 실명과 코드 연결은 담당자가 별도로 관리한다.
- 첫 점검 시간은 안내·체험·파일 전달을 포함해 10~15분으로 잡는다. 실제 소요 시간을 별도로 기록한다. 화면의 시계는 시뮬레이션 시간이다.
- 담당자는 참여자 대신 선택하거나 특정 조사 순서·방벽을 정답으로 안내하지 않는다.

## 참여자에게 전달할 안내

아래 안내와 체험 주소를 담당자가 참여자에게 전달한다.

> HERO에 본인 계정으로 로그인한 뒤 아래 주소를 열어주세요. 패널·문서·동료·연락 수단을 눌러 살펴볼 수 있습니다. 대상을 여는 것은 무료이고 시간을 표시한 행동을 실행하면 게임 시간이 흐릅니다. 모든 대상을 살펴볼 필요는 없습니다. 준비됐다고 느끼면 ‘다음 행동 결정’을 눌러 본인의 판단으로 진행해주세요. 체험을 마치면 회고의 세 문항과 판단 근거를 작성하고, ‘체험 의견과 판단 기록 내려받기’를 눌러 받은 JSON 파일을 담당자에게 전달해주세요. 파일을 받기 전에는 새로고침하거나 ‘다시 해보기’를 누르지 마세요.

## 진행 중 관찰

담당자는 다음 행동이 가능한지 살펴보고 막힌 위치를 기록한다. 수행을 유도하는 체크리스트로 참여자에게 제시하지 않는다.

1. 기기실의 조사 대상과 확대 화면을 찾을 수 있는가.
2. 무료 열람과 시간 비용이 있는 확인 행동을 구분하는가.
3. 확인한 단서를 다시 읽거나 조사 대상을 바꿀 수 있는가.
4. 동료 화면을 여는 것과 별도 근거의 독립확인을 구분하는가.
5. 원하는 시점에 판단을 열고 선택을 확정할 수 있는가.
6. 회고에서 의견을 작성하고 받은 파일의 위치를 찾을 수 있는가.

기기·브라우저 종류, 실제 소요 시간, 막힌 화면과 사용자의 표현을 간단히 기록한다. 초대 토큰·카카오 계정·이메일은 기록하지 않는다.

## 의견 전달과 관리자 검토

참여자가 받은 파일을 담당자에게 직접 전달한다. 현재 앱에는 자동 제출 또는 의견 수집함이 없다. 담당자는 파일을 참여코드와 연결해 관리하되, 의견 JSON 본문에 실명이나 계정 정보를 추가하지 않는다.

관리자는 [시나리오 관리](https://hero-dnr.pages.dev/admin/scenarios)에서 ‘체험 의견 파일 검토 열기’를 누른 뒤 전달받은 JSON 파일을 선택한다. S02 v4 본문 SHA, 체험 버전 2, 문항과 행동 순서·시간 비용·확인 단서가 일치하면 읽기 쉬운 결과가 표시된다. 구조가 다른 파일, 변경된 비용·순서·단서 또는 64KB를 넘는 파일은 거부된다. 원본 파일을 임의로 고치기보다 해당 참여자에게 내려받은 원본인지 확인한다.

파일 검토는 이 기기에서 이루어지며 서버 업로드·저장·콘텐츠 승인 반영을 하지 않는다. 검사 통과는 파일의 일관성 확인이며 실제 참여 여부나 의견 진위를 인증하는 것은 아니다. Codex Chrome 확장의 파일 접근 권한은 자동 파일 선택에 관한 설정이며, 사용자가 이 화면에서 직접 파일을 선택하는 것과 구분한다.

## 두 명의 의견을 보고 결정할 내용

먼저 진행을 막는 문제를 고치고, 이어 조사 대상의 표시·확대 화면·현장 메모·판단 입구 중 혼란을 준 부분을 보완한다. ‘정보 때문에 판단을 바꿨다’는 답변은 해당 확인 단서와 행동 순서에 연결해 읽는다. 두 명의 응답 비율만으로 학습 효과를 확정하지 않는다.

다음 단계의 이동·애니메이션·별도 게임 엔진 도입은 ‘직접 조사하는 느낌’과 ‘다른 방법으로 다시 확인하고 싶은지’에 대한 실제 의견을 받은 뒤 범위를 정한다. 체험 UI 개선과 전체 S02 본문 변경은 구분하고, 본문을 바꾸면 새 버전으로 검토·승인한다.

## 첫 점검 현황

2026년 10월 15일 관리자 조직 화면에서 중앙연구원·한울3발의 운영 상태와 각 교육담당자 1명의 활성 상태를 확인했다. 사용자는 같은 날 두 참여자가 아직 체험 전이라고 확인했다. 작업자 개인의 초대 수락은 아직 확인하지 않았다. 실제 완료와 의견 전달 후 다음 표를 갱신한다.

| 참여코드 | 로그인 확인 | 체험 완료 | 의견 원본 전달 | 진행 문제 |
|---|---|---|---|---|
| CRI02 | 미확인 | 체험 전 | 미수집 | 미확인 |
| HANUL02 | 미확인 | 체험 전 | 미수집 | 미확인 |

자동 검증에 쓴 의견 파일은 실제 참여자 결과로 집계하지 않는다.
