# 캠페인 콘텐츠 공개 상태 안내 보완

2026-10-15 · 캠페인의 고정 ‘10월 시즌 · 개발 중’ 문구와 S01~S03 ‘준비중’ 목록이 실제 시즌 공개 여부·계정 역할과 무관하게 표시되고 있었다. 조회 실패 때도 같은 준비 목록을 보여 공개 전 콘텐츠로 오해할 수 있었다.

## 변경

- 캠페인 상단을 튜토리얼·탐색형 체험·현재 시즌 경쟁 플레이의 이용 안내로 바꿨다. 특정 월을 고정 표시하지 않는다.
- 참여자는 기존의 활성 시즌 → 시즌 연결 → 게시 버전 → 활성 경쟁 시나리오 조회 결과로 이용 가능한 콘텐츠를 본다. 시즌 제목은 조회한 실제 제목을 사용한다.
- 관리자·교육담당자에게는 참여자 계정과 운영 계정의 이용 범위를 안내하고 각각 운영 현황·사업소 관리로 연결한다. 공개 상태를 조회하지 않은 채 ‘준비중’이라고 표시하지 않는다.
- 시즌 없음, 현재 시즌에 공개된 경쟁 콘텐츠 없음, 조회 실패를 구분한다. 조회 실패에는 다시 확인 버튼을 제공한다.
- 순위 RPC의 빈 결과는 ‘순위 없음’이 아니라 진행 중인 시즌 없음으로 표시한다. RPC는 활성 시즌에 미참여자도 0 HP 행을 반환하므로 이 경우와 구분한다.
- 경쟁 카드의 순번을 임의로 다시 매기지 않고 ‘경쟁’으로 표시한다. 실제 장 번호와 제목은 공개된 제목을 유지한다.
- 튜토리얼·경쟁 카드에 접근성 이름을 명시하고 직무 관점은 이용자가 이해할 수 있는 표시명을 사용한다.

시나리오 내용·승인·게시 상태, 시즌 연결, 계정 권한과 점수 처리는 변경하지 않는다. 재조회는 읽기 작업만 수행한다. 관리 계정에서 경쟁 플레이 권한을 부여하지 않는다.

## 검증 범위

`e2e/campaign-availability.spec.ts`는 360px·390px에서 공개 콘텐츠, 운영 계정 2종, 시즌 없음, 연결·게시 버전·활성 콘텐츠 없음, 네 단계 조회 실패 및 재시도 복구를 확인한다. 공개 콘텐츠 화면에는 접근성 검사를 포함한다. 기존 탐색형 체험 흐름도 병행 확인한다.

[첫 파일럿 참여코드와 진행 기록](72_S02_EXPLORATION_PARTICIPATION_CODES.md)은 변경 없이 유지한다.
