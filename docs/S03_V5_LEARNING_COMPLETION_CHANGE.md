# S03 v5 — 조작 여부보다 학습목표 달성을 평가

## 1. 승인 범위

2026-10-13 사용자에게 S03의5개 관점별 유지/보완 방향과 ‘불필요한 조작 회피도 근거 확인·팀 공유를 갖추면 성공적인 학습 완료로 인정’하는 설계를 제안했고, 사용자가 **“제안 승인합니다. 이어서 계속 진행”**이라고 답했다.

이는 콘텐츠 개정 방향에 대한 승인이다. S03 v5의 HF·운전맥락·익명화·Just Culture·사건해설5개 영역을 최종 PASS로 기록한 승인이 아니다. 사람 검토 기록은0/5를 유지하며 자동 승인·게시·시즌 연결은 수행하지 않는다.

## 2. 적용 내용

| 변경 | 구현 |
|---|---|
| 조작 필요성 확인 | 초기/중간의 재확인 선택은 즉시 엔딩으로 가지 않고 `event_no_action_basis`로 이동 |
| 사실·교육 경계 | 필요성 확인 결과는 HERO의 교육용 대안 경로이며 실제 사건에서 수행됐다는 뜻이 아님을 명시 |
| 학습 완료 조건 | 미조작 근거의 공유·기록·인계 결정 후에만 `safe_no_action_end` 도달 |
| 미조작 완료 엔딩 | safe_complete: 불필요한 조작을 피하고 근거 공유·인계 완료 |
| 남은 불확실성 | 추가 확인 요청은 기존 safe_stop 엔딩으로 연결 |
| 학습 지표 | 초기 확인의 안전/절차/의사소통과 근거 공유·인계 지표를 시나리오 효과로 반영. 단순 멈춤 횟수 보너스 없음 |
| 조작 계속 경로 | 정상 반응만으로 조작 필요성 판단의 적절성을 입증하지 않는다는 엔딩 안내 추가 |
| 기준값 표현 | 현재 운전상태의 기준값·설정 적용 조건·예상반응을 함께 대조하도록 보완 |
| 원인 해설 | 인과사슬의 ‘독립검증 없이’ 표현을 ‘적정성을 별도로 확인하지 않고’로 정리. HU Tool 분류 자체는 전문가 검토 대상 |
| HU Tool 구분 | 동료확인과 독립검증이 같은 기법이 아니며 실제 사건의 공식 제도요건 위반 판정이 아님을 교훈에 명시 |
| 공개 화면 안내 | 공식 출처 원문에는 사건 식별정보가 있을 수 있고 화면의 정보 최소화가 완전 비식별화를 의미하지 않음을 안내 |

전역 `SCORE_RULE_VERSION=1.0.0`과 엔딩 기본점수는 변경하지 않았다. 공유 엔진 계약이 아니라 S03의 학습 경로·효과·엔딩 의미가 바뀌므로 시나리오 version을4→5로 올린다. 미조작 완료237점은 이 경로의 확인/공유/인계 효과를 반영한 비교 결과이며, 모든 정보/카드 조합을 다른 경로와 일률적으로 같게 만든 값은 아니다.

## 5. 회귀 검증 범위

신규 엔진 회귀4개는 확인/인계 전 즉시 완료 금지,20개 seed의 미조작 학습 완료 비교, 추가 불확실성의 safe_stop 유지, 교육용 대안/공식 사실 구분을 확인한다. 실제 브라우저·4종 실기기·KINS 원본 대조·운영 승인/게시 검증은 이 기록에 포함하지 않는다. 새 GitHub Actions 및 운영 배포는 별도로 실행하지 않는다.

로컬 전체 검증: typecheck·lint·397개 단위 테스트(엔진23+웹374)·프로덕션 빌드·초기번들 예산·라우트 분할·클라이언트 비밀값·오디오17개·TASKLIST86개 검증 통과. S03 schema/strict 경로·source/promotion/approval-hash/원인추적성 및 생성자료 freshness도 통과했다. 전체 CI/DB/실기기 검증의 새 실행 기록은 아니다.

모바일 관리자 검토 E2E14개는 실행을 시도했으나 이 환경에 Chromium 실행 파일이 없어 브라우저 시작 전에 중단됐다. Chromium 설치 다운로드도 손상된0MiB ZIP으로 실패했다. 화면/접근성 회귀 PASS가 아니며 앱 동작 실패로 판정한 것도 아니다. 검토 PR을 병합/운영 반영하기 전에 브라우저가 설치된 로컬 환경에서 `e2e/admin-scenario-review.spec.ts`를 같은v5 소스·loopback 모의API로 다시 검증한다. 기존 설정은 유지하고 원격DB·Edge·운영 콘텐츠를 변경하지 않는다.
