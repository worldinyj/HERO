# 아기 수리 — 3포즈 V1

2026-10-12 사용자가 선택한 아기 수리 시안을 기준으로 built-in image_gen에서 독립 투명 배경 이미지를 제작했다. 큰 둥근 머리, 짧은 팔다리, 크림색 주둥이, 네이비 작업복과 앰버 포인트를 유지했다.

| 포즈 | 원본 | 화면용 | 용도 |
|---|---|---|---|
| 환영 | suri-welcome-v1.png | /images/mascot/suri-welcome-v1.webp | 로그인·첫 학습 안내 |
| 함께 확인 | suri-check-v1.png | /images/mascot/suri-check-v1.webp | 브리핑·상황 확인 |
| 회고 | suri-reflect-v1.png | /images/mascot/suri-reflect-v1.webp | 결과·회고 |

PNG는 1254×1254 RGBA 원본이며, WebP는 640×640, 품질 85, 알파 채널을 유지한 출력이다. 화면용 파일은 각각 약 51~57KB다. `asset-manifest.json`에 원본·화면용 크기와 해시를 기록했다. 원본 PNG는 공개 웹 폴더 밖에 둔다.

첫 화면은 환영 포즈만 로드한다. 캐릭터는 장식용 이미지로 처리하고 안내·버튼은 실제 HTML 텍스트로 제공한다. 이미지 실패 시 자리를 유지하며 로그인 동작을 막지 않는다. 나머지 포즈의 화면 연결은 후속 단계다.

KHNP 독립 로고는 공식 CI 원본을 별도로 사용한다.

- 출처: https://www.khnp.co.kr/main/contents.do?key=2238
- 원본 URL: https://www.khnp.co.kr/site/main/images/contents/cts86_img09.png
- 배포 경로: /images/brand/khnp-signature.png

캐릭터 안전모의 로고는 생성 그림의 일부이며 독립 공식 로고 파일과 구분한다. 앱의 주요 기관 표시는 공식 원본 파일을 그대로 표시한다.

## 생성 브리프

세 포즈 모두 승인 시안을 얼굴·비율·복장 참조로 사용했다. 전신·한 캐릭터·투명 배경, 부드러운 인형 질감, 작은 검은 눈, 둥근 크림색 주둥이, 흰 안전모·네이비 작업복·앰버 포인트를 요청했다. 성체 비율, 긴 수염, 사람 손가락, 텍스트 패널과 장식 효과를 제외했다.

- 환영: 서서 한 손에 닫힌 노트를 들고 다른 작은 발로 부드럽게 인사.
- 함께 확인: 서서 열린 노트를 양손에 들고 차분하게 살핌. 정답 표시와 설비 설정값 없음.
- 회고: 앉아서 한 발을 볼에 대고 조용히 생각함. 축하·비난·슬픔 연출 없음.
