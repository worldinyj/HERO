# S01 S02 공식 근거와 이용조건 검토

S01과 S02의 사건별 공식 관리번호를 확보했다. S02는 해당 2024년 정책브리핑 페이지의 텍스트 이용조건까지 확인해 사람 검토 준비 상태로 이동한다. S01도 현재 v4가 실제 사용하는 범위의 이용조건을 확인해 사람 검토 준비 상태로 이동한다. 사용하지 않는 기존 미션 보고서 첨부는 승격 장애에서 제외한다.

## 사건별 공식 기록

[원자력안전정보공개센터 원전 사고·고장](https://nsic.nssc.go.kr/information/reguDataActive.do?nsicDtaTyCode=nppAccient)에서 목록의 사건제목을 열어 상세를 확인했다. 상세는 같은 URL의 창으로 표시되어 관리번호와 화면 식별자를 함께 기록한다. 임의의 별도 상세 URL은 만들지 않는다.

| 시나리오 | 관리번호 | 화면 식별자 | 확인한 내용 |
|---|---|---|---|
| S01 | 고리1호기-2012-4 | 832 | 전원상실·비상발전기 기동실패, 12분 전력공급 중단과 보고 지연 |
| S02 | 신한울1호기-2024-1 | 1006 | 잘못된 회로 구성과 조작부 오인, 제작·공급과정 확인 및 인간공학 원인, 출력 감소 후 미임계 진행, 재발방지대책 |

S02의 직접 사실과 도면·공급과정·인간공학 원인은 상세 조사 결과에 근거한다. 시간압박·독립확인·동료확인·감독자 소통은 HERO의 교육용 조건과 확인 지점이며, 조사기관이 실제 사건에서 그 절차의 부재를 확인했다고 쓰지 않는다. 세부 설정값·결선·복구 절차는 공개 시나리오에 포함하지 않는다.

첨부 조사보고서의 다운로드는 완료하지 못했다. 이번 근거는 실제로 읽은 공식 상세 내용과 관리번호이며 첨부 PDF를 검토한 것으로 기록하지 않는다.

## S01의 개별 이용조건

[2012년 6월 한수원 보도자료](https://www.khnp.co.kr/main/selectBbsNttView.do?key=2289&bbsNo=71&nttNo=24384)에서 본문에 공공누리 제1유형 표시를 확인했다. 안전문화·리더십 개선권고 맥락의 보조 근거로 추가한다.

기존 [2012년 미션 최종보고서 공지](https://www.khnp.co.kr/main/selectBbsNttView.do?bbsNo=67&key=2288&nttNo=22297)는 현재 홈으로 이동하고, 공지 목록의 IAEA 제목 검색에서도 회수되지 않았다. 다른 보도자료의 제1유형을 이 첨부에 승계하지 않는다. 해당 첨부의 이용허락은 확인하지 않았다. 다만 현재 v4는 이 첨부의 문장·도표·그림을 재사용하지 않으며, 사건 사실은 별도 공식 기록으로 대조하고 안전문화 맥락은 위 보도자료 본문에 근거한다. 따라서 사용하지 않는 첨부의 조건 확인을 전체 시나리오의 승격 장애로 두지 않는다.

## S02의 개별 이용조건

[2024년 4월 17일 원안위 직접 원문](https://www.nssc.go.kr/ko/cms/FR_BBS_CON/BoardView.do?BBS_SEQ=46557&BOARD_SEQ=5&MENU_ID=190&SITE_NO=2)을 확보했다. 이 호스트의 표시는 공공누리 제4유형이다. [제4유형 안내](https://www.kogl.or.kr/info/licenseType4.do)에 따라 상업적 이용과 변경 허용으로 해석하지 않는다.

같은 날짜·제목·사건 내용을 가진 [정책브리핑 원문](https://www.korea.kr/briefing/pressReleaseView.do?newsId=156625772)에는 해당 텍스트에 한하여 공공누리 제1유형을 적용한다고 명시되어 있다. 다른 연도의 같은 제목을 적용한 것이 아니다. 이 페이지 텍스트를 공개 해설의 이용조건 근거로 선택한다. 두 호스트의 서로 다른 표시를 모두 보존하고, 정책브리핑의 텍스트 조건을 원안위 호스트나 비텍스트 자료로 확장하지 않는다.

HERO 해설은 출처를 표시한 독립 작성 문안이다. 원문 표현·사진·이미지·도표·PDF는 게임 자산으로 복제하지 않는다. NSIC 상세는 추가 사건 사실의 대조에만 사용한다.

## 현재 승격 상태

| 시나리오 | 사건 사실 | 이용조건 | 사람 검토 | 판정 |
|---|---|---|---|---|
| S01 v4 | 사건별 기록 확보 | 독립 작성 사실 설명·확인된 보도자료 본문 제1유형; 미션 첨부 재사용 없음 | 대기 | REVIEW READY |
| S02 v4 | 사건별 기록과 직접 공식 원문 확보 | 해당 정책브리핑 텍스트 제1유형 확인 | 대기 | REVIEW READY |

사람 검토와 최종 승격은 현재 v4 콘텐츠 SHA256에 대해 기록해야 한다. S03의 사용자 승인을 S01·S02에 적용하지 않는다. 실제 승인과 게시 전까지 공개 경쟁 콘텐츠로 승격하지 않는다.

## 사용자 검토 응답 반영

2026-10-14 사용자는 비상업적 이용 목적을 설명했고 S02는 아직 검토 중이라고 답했다. 이 답변을 콘텐츠 승인 또는 첨부 이용허락 증빙으로 기록하지 않았다. [공공누리 공식 이용조건](https://www.kogl.or.kr/info/license.do)은 비상업 조건과 변경 조건을 구분한다. 이번 S01 판단은 모든 공개 자료가 자유 이용이라는 가정이 아니라 현재 v4의 실제 사용 범위를 확인한 결과이다. 두 JSON의 내용·버전·SHA256과 사람 승인 대기 상태는 그대로 유지한다.
