# S01 S02 공식 근거와 이용조건 검토

S01과 S02의 사건별 공식 관리번호를 확보했다. S02는 해당 2024년 정책브리핑 페이지의 텍스트 이용조건까지 확인해 사람 검토 준비 상태로 이동한다. S01도 현재 v4가 실제 사용하는 범위의 이용조건은 확인했다. 다만 정식 검토 준비에는 원인·방벽·재발방지대책 추적표 보완이 남아 있다. 사용하지 않는 기존 미션 보고서 첨부는 승격 장애에서 제외한다.

S02의 직접 사실과 도면·공급과정·인간공학 원인은 상세 조사 결과에 근거한다. 시간압박·독립확인·동료확인·감독자 소통은 HERO의 교육용 조건과 확인 지점이며, 조사기관이 실제 사건에서 그 절차의 부재를 확인했다고 쓰지 않는다. 세부 설정값·결선·복구 절차는 공개 시나리오에 포함하지 않는다.

첨부 조사보고서의 다운로드는 완료하지 못했다. 이번 근거는 실제로 읽은 공식 상세 내용과 관리번호이며 첨부 PDF를 검토한 것으로 기록하지 않는다.

## S01의 개별 이용조건

[2012년 6월 한수원 보도자료](https://www.khnp.co.kr/main/selectBbsNttView.do?key=2289&bbsNo=71&nttNo=24384)에서 본문에 공공누리 제1유형 표시를 확인했다. 안전문화·리더십 개선권고 맥락의 보조 근거로 추가한다.

기존 [2012년 미션 최종보고서 공지](https://www.khnp.co.kr/main/selectBbsNttView.do?bbsNo=67&key=2288&nttNo=22297)는 현재 홈으로 이동하고, 공지 목록의 IAEA 제목 검색에서도 회수되지 않았다. 다른 보도자료의 제1유형을 이 첨부에 승계하지 않는다. 해당 첨부의 이용허락은 확인하지 않았다. 다만 현재 v4는 이 첨부의 문장·도표·그림을 재사용하지 않으며, 사건 사실은 별도 공식 기록으로 대조하고 안전문화 맥락은 위 보도자료 본문에 근거한다. 따라서 사용하지 않는 첨부의 조건 확인을 전체 시나리오의 승격 장애로 두지 않는다.

## S02의 개별 이용조건

[2024년 4월 17일 원안위 직접 원문](https://www.nssc.go.kr/ko/cms/FR_BBS_CON/BoardView.do?BBS_SEQ=46557&BOARD_SEQ=5&MENU_ID=190&SITE_NO=2)을 확보했다. 이 호스트의 표시는 공공누리 제4유형이다. [제4유형 안내](https://www.kogl.or.kr/info/licenseType4.do)에 따라 상업적 이용과 변경 허용으로 해석하지 않는다.

같은 날짜·제목·사건 내용을 가진 [정책브리핑 원문](https://www.korea.kr/briefing/pressReleaseView.do?newsId=156625772)에는 해당 텍스트에 한하여 공공누리 제1유형을 적용한다고 명시되어 있다. 다른 연도의 같은 제목을 적용한 것이 아니다. 이 페이지 텍스트를 공개 해설의 이용조건 근거로 선택한다. 두 호스트의 서로 다른 표시를 모두 보존하고, 정책브리핑의 텍스트 조건을 원안위 호스트나 비텍스트 자료로 확장하지 않는다.

HERO 해설은 출처를 표시한 독립 작성 문안이다. 원문 표현·사진·이미지·도표·PDF는 게임 자산으로 복제하지 않는다. NSIC 상세는 추가 사건 사실의 대조에만 사용한다.

## 현재 승격 상태

| 시나리오 | 사건 사실 | 이용조건 | 사람 검토 | 판정 |
|---|---|---|---|---|
| S01 v4 | 사건별 기록 확보 | 독립 작성 사실 설명·확인된 보도자료 본문 제1유형; 미션 첨부 재사용 없음 | 대기 | 추적표 보완 대기 (이용조건 보류 아님) |
| S02 v4 | 사건별 기록과 직접 공식 원문 확보 | 해당 정책브리핑 텍스트 제1유형 확인 | 대기 | REVIEW READY |

사람 검토와 최종 승격은 현재 v4 콘텐츠 SHA256에 대해 기록해야 한다. S03의 사용자 승인을 S01·S02에 적용하지 않는다. 실제 승인과 게시 전까지 공개 경쟁 콘텐츠로 승격하지 않는다.

## 사용자 검토 응답 반영

2026-10-14 사용자는 비상업적 이용 목적을 설명했고 S02는 아직 검토 중이라고 답했다. 이 답변을 콘텐츠 승인 또는 첨부 이용허락 증빙으로 기록하지 않았다. [공공누리 공식 이용조건](https://www.kogl.or.kr/info/license.do)은 비상업 조건과 변경 조건을 구분한다. 이번 S01 판단은 모든 공개 자료가 자유 이용이라는 가정이 아니라 현재 v4의 실제 사용 범위를 확인한 결과이다. 두 JSON의 내용·버전·SHA256과 사람 승인 대기 상태는 그대로 유지한다.

## KINS 정책 및 HTO 시안 반영

사용자는 2026-10-14 KINS 홈페이지 정책 중 KINS가 저작재산권 전부를 보유한 저작물은 별도 허락 없이 자유 이용할 수 있다는 문구를 제공했다. 해당 기관·권리 보유 범위에 적용하는 정책 근거로 반영하며 한수원·IAEA 자료의 권리로 확장하지 않는다. 검색 도구에서는 회수하지 못했으나 실제 브라우저로 [KINS 저작권 보호정책](https://www.kins.re.kr/copyright)을 열어 해당 문구를 확인했다. 같은 정책은 공공누리 표시 확인과 구체적 출처표시, 제3자 권리가 포함된 자료의 별도 조건도 안내한다. 정책 원문을 확인한 것이며 특정 첨부의 소유권을 별도 확인했다고 기록하지 않는다. [저작권법 제24조의2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1033063627)도 참고했다.

S02 v4의 별도 HTO 회고 시안을 관리자 미리보기에 추가했다. 정규화한 시나리오 JSON의 SHA256에 연결하며 본문의 승인 SHA256은 바꾸지 않는다. 공식 사실, HERO의 HTO 해석, 교육용 추가 조건을 구분한다. 세 상호작용과 개인·기술·조직 개선 질문을 제공하되 입력을 저장하거나 점수를 변경하지 않는다. 표시·조직 조건을 바꾸는 정성적 가상 판단 연습을 별도 관리자 UI에 구현했다. 동일한 판단을 유지하면서 기술·조직 조건의 설명을 비교하며, 조건 또는 판단 변경 시 이전 해설을 제거한다. 잠재적인 회로·도면 오류는 두 조건 모두에 남겨 둔다. 이는 실제 사건의 결과·확률 예측이나 기존 게임 엔진의 사건·HP 계산이 아니다. 근거는 [IAEA-TECDOC-1846 §2.6](https://www-pub.iaea.org/MTCD/Publications/PDF/TE-1846web.pdf)과 IAEA HTO 교육자료이다.

CI에서 S01의 정식 review_ready 상태에는 재발방지대책과 추적표가 필요함을 확인했다. 기존 v4에는 correctiveActions가 없어 원문과 승인 대상 내용을 유지하면서 내부 보류 상태를 정정했다. 이용조건 완료 판정은 유지하며 검증 규칙을 완화하지 않았다. S02 HTO 시안 진행과는 독립된 보완 사항이다.

## S02 본문 검토와 HTO 의견의 분리

관리자 검토 패널은 정식 검토 준비 상태의 S02와 승인된 S03를 각각 선택할 수 있다. 선택한 본문의 ID·버전·정규화 해시가 일치해야 본문 검토 결과 파일을 내려받을 수 있다. 대상 전환 시 미확정 확인·입력 상태를 초기화하고 이전 요청의 늦은 응답을 무효화한다.

HTO 시안 의견은 `hto_draft_feedback` 형식으로 따로 내려받는다. 현재 S02 본문 SHA와 HTO UI·조건 비교 모델·스타일의 별도 SHA를 포함한다. 기존 `human_review_submission` 가져오기는 이 파일을 거부한다. 의견 작성·다운로드로 사람 검토 통과나 콘텐츠 승인·게시가 자동 반영되지 않는다. 본문 검토 승인 대기는 유지한다.
